# Ultimate README Guide

> The definitive, no-BS guide to writing README files that people actually read.

## What Is This

A comprehensive, opinionated specification for writing high-quality README files.
Built from analyzing top-tier open-source projects, it covers structure, formatting,
visual content, and mandatory elements — so you never have to guess what a great
README looks like.

The guide lives in [`The Ultimate README Guide.md`](./The%20Ultimate%20README%20Guide.md).
This README is an example of what it produces.

---

## How to Use This Guide

The guide is a single Markdown file designed to be consumed in multiple ways.

### As an AI Agent Prompt

Feed the guide to any LLM-based coding assistant (GitHub Copilot, Claude, Cursor,
ChatGPT, etc.) as a system prompt or reference document. The agent will then write
or review READMEs that follow the spec.

**Example workflow:**

1. Copy the contents of `The Ultimate README Guide.md`
2. Paste it into your AI agent's system prompt, custom instructions, or context window
3. Ask the agent to write a README for your project
4. The agent produces a README that follows every rule in the guide

**Tips for best results:**
- Provide your project's source code alongside the guide so the agent can extract
  real details (tech stack, structure, dependencies)
- If the output is too long, ask the agent to prioritize sections relevant to your
  project type (e.g., skip EDA for a CLI tool)
- Use the guide's checklist as a validation step — ask the agent to verify
  its output against every checkbox

### As a Code Review Reference

Use the checklist section to review existing READMEs. Ask your AI agent:

> "Review this README against the checklist in the guide. Flag any missing sections
> or violations."

### As a Template

The guide contains copy-pasteable template blocks for every section. Find the
sections you need, assemble them, and fill in your project's details.

### As a Teaching Tool

New contributors can read the guide to understand what's expected in project
documentation. Share it with your team to establish a consistent standard.
